# Car Rental Management System

A web-based Car Rental Management System designed to streamline vehicle rental operations by providing efficient management of customers, vehicles, reservations, and rental transactions.

## Overview

The Car Rental Management System helps rental businesses manage their fleet, monitor vehicle availability, process bookings, and track rental records through a centralized platform.

## Features

### Customer Management
- Customer registration and profile management
- Customer information tracking
- Rental history monitoring

### Vehicle Management
- Add, update, and remove vehicles
- Vehicle availability tracking
- Vehicle categorization and status management
- Maintenance status monitoring

### Reservation Management
- Online vehicle reservation
- Booking approval and cancellation
- Rental schedule management
- Real-time vehicle availability checking

### Rental Transactions
- Vehicle check-in and check-out processing
- Rental agreement generation
- Payment recording and monitoring
- Rental duration tracking

### Dashboard & Reports
- Rental transaction summaries
- Vehicle utilization monitoring
- Customer activity reports
- Revenue and booking analytics

## User Roles

### Administrator
- Manage vehicles
- Manage customers
- Monitor reservations
- Generate reports
- Manage system settings

### Staff
- Process rentals
- Handle reservations
- Update vehicle status
- Manage customer transactions

### Customer
- Browse available vehicles
- Make reservations
- View booking history
- Manage profile information

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/car-rental-management-system.git
```

2. Navigate to the project folder

```bash
cd car-rental-management-system
```

3. Install dependencies

```bash
npm install
```

4. Configure the database connection
